You already have a strong base. The best next features depend on whether you want `SecureChat` to feel more social, safer, or more polished.

**High Impact**
- `Message reactions`: quick emoji reactions make chats feel much more alive.
- `Reply to message`: helps keep conversations clear, especially with media.
- `Pinned chats`: lets users keep important friends at the top.
- `Typing indicator`: small but makes chat feel realtime and modern.
- `Online / last seen status`: helps people know when to message.
- `Read receipts`: complements the unread ranking you already built.

**Social Features**
- `User profiles`: public mini-profile with bio, interests, city, and shared friends.
- `Mutual friends`: useful for trust and discovery.
- `Block user`: very important for a friend-making platform.
- `Report user / report message`: especially useful since you already started AI safety features.
- `Friend suggestions`: based on mutual friends or recent interactions.
- `Profile view modal`: click avatar anywhere to see profile + actions.

**Chat Features**
- `Edit message`
- `Forward message`
- `Star / save message`
- `Group chats`
- `Voice notes`
- `Multiple attachments in one message`
- `Drag and drop uploads`
- `Link previews`

**Safety / AI Features**
- `Auto-warning badge`: if a message was already checked and marked risky, show a small warning icon in chat.
- `Report with AI summary`: attach AI result when reporting a suspicious message.
- `Scam pattern detection`: beyond link checks, scan text for payment scams, impersonation, urgency tactics.
- `Profile image moderation during onboarding`
- `Safety tips banner`: for new users or suspicious chats.

**Call Features**
- `Incoming call UI`
- `Call ringing / accept / decline`
- `Missed call history`
- `Screen sharing`
- `Camera switch / device selection`
- `Call duration and call logs`

**Polish**
- `Desktop notifications`
- `Mobile responsive chat refinements`
- `Keyboard shortcuts`
- `Dark/light theme improvements`
- `Better chat search`: jump between matches instead of just filtering
- `Archived chats`

If you want the best next 5, I’d recommend:
1. `Block and report user`
2. `Reply to message`
3. `Typing indicator`
4. `Read receipts`
5. `Incoming call accept/decline flow`
